Programação Web

Como Funcionam HTML e CSS?

A Web moderna é construída através do trabalho conjunto entre linguagens de marcação e estilização.

🌐

HTML (HyperText Markup Language)

O Esqueleto da Página

O HTML utiliza tags (como <h1>, <p> e <div>) para estruturar o conteúdo do site. Ele define onde ficam os títulos, parágrafos, botões e imagens.

🎨

CSS (Cascading Style Sheets)

A Estilização Visual

O CSS é responsável pelo design do site. Com ele, aplicamos cores, fontes, espaçamentos, layouts responsivos e animações, transformando a estrutura bruta do HTML em uma interface agradável.

⚙️

A Integração das Tecnologias

Estrutura + Estilo + Lógica

Enquanto o HTML cria a estrutura e o CSS cuida da estética, o JavaScript adiciona interatividade dinâmica, permitindo criar aplicações web completas e responsivas.

Robótica Educacional

A Roda de Newton Automatizada

Nesta seção, aplicamos o controle de hardware para criar uma simulação do Disco de Newton automatizado.

Em um projeto físico, o motor DC é controlado por um microcontrolador (como o Arduino) via sinal PWM (Pulse Width Modulation), permitindo ajustar com precisão a velocidade de rotação do disco colorido.

💻 Controle PWM 🤖 Arduino Uno ⚙️ Motor DC 5V 🎨 Disco de Cores
MOTOR: LIGADO

Em alta rotação, a sobreposição do espectro visível gera a ilusão da cor branca.

Física & Tecnociência

Óptica Visual: O Olho Humano

Do ponto de vista da física, o olho funciona como uma câmera fotográfica. A luz atravessa os meios refratários até projetar uma imagem focalizada na retina.

Córnea & Cristalino

Lentes Convergentes

A córnea realiza a refração principal da luz. O cristalino altera sua curvatura (acomodação visual) para focar objetos a diferentes distâncias.

Íris & Pupila

Diafragma Ajustável

A íris controla o diâmetro da pupila em resposta à luminosidade, ajustando a quantidade de luz que entra no olho.

Retina & Nervo Óptico

Sensor e Transmissão

A retina possui fotorreceptores (cones e bastonetes) que convertem a luz em impulsos elétricos, enviados ao cérebro pelo nervo óptico.
